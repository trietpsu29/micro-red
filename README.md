# Micro Reddit

This is the project from [The Odin Project](https://github.com/TheOdinProject) curriculum — a simple Reddit-style application built with **Ruby on Rails**, focusing on Active Record, database migrations, model validations, and associations.

## Features

- Create users
- Create posts
- Create comments on posts
- Associate posts with users
- Associate comments with users and posts
- Validate user, post, and comment data
- Database migrations and schema management
- Basic Active Record database interactions
- Rails console for creating and testing records

## Skills Learned

### Ruby on Rails

- Active Record basics
- Active Record models
- Database migrations
- Creating and modifying database tables
- Basic model validations
- `belongs_to` associations
- `has_many` associations
- Foreign key columns
- Creating and querying records with Active Record
- Using the Rails console
- Testing validations and associations

## Challenges

- Understanding how Active Record models map to database tables
- Understanding Rails database migrations and how to modify an existing schema
- Understanding foreign keys and how they connect associated models
- Learning the difference between `belongs_to` and `has_many`
- Understanding how Rails automatically handles associations
- Working with model validations
- Testing model behavior and associations through the Rails console
- Getting familiar with Rails conventions and Active Record methods
